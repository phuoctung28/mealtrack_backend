# Single-Thread Chatbot Implementation Plan

**Status:** Proposed

The implementation plan is split to follow the repository's documentation size guideline:

- [Foundation Plan](./implementation-plan-foundation.md) — scope, file map, contract approval, domain, migration, repositories/UoW, AI adapter, and MealTrack context.
- [Delivery Plan](./implementation-plan-delivery.md) — application orchestration, API, observability/privacy, verification, one-user beta, broader-release gates, and pull-request slicing.

Execute the foundation plan first, then the delivery plan. Both are normative.
